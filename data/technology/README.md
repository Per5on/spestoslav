# Source-backed technology sample

Exactly1,000 distinct Techmart source product codes observed from public HTML analytics metadata with robots/path checks, bounded sequential reads and cached source evidence. No price, GTIN or image licence is inferred. Product grouping follows source-category pages and is not a measured market-share allocation.

Freeze JSON plus docs/TECHNOLOGY_1000.md preserve all source links. Collector rejects unsupported hosts, enforces page bounds and refuses to pad incomplete results. Malformed source analytics records are skipped; only well-formed explicit identities are eligible. Import is idempotent and additive; inactive flags and existing barcodes are retained.
