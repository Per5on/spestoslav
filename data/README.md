# Bulgarian postal-code reference data

The CSV in this directory is generated by the WorldPostalCode importer. It is
not committed as a completed dataset until the importer has been run with
network access and its output reviewed.

## Generate

From the repository root:

```bash
python -m pip install requests beautifulsoup4
python scripts/import_worldpostalcode_bulgaria.py
```

The importer starts at https://worldpostalcode.com/bulgaria/, follows region
and municipality links in the site's **Regions** navigation, extracts
settlement/postal-code pairs, deduplicates records, and writes:

- `bulgaria_postal_codes.csv` — UTF-8 with BOM for spreadsheet compatibility.
- `worldpostalcode_import_errors.txt` — created only if pages fail to load.

CSV columns: `settlement_name, postal_code, municipality_or_region, source_url`.

The script uses a descriptive User-Agent, a request timeout, and a delay
between requests. Review errors and sample records before importing into the
application. The source states that its lists are compiled from GeoNames,
free sources and manually curated datasets; treat the result as a third-party
reference, not an official Bulgarian postal register. Preserve `source_url`
for provenance and independently validate important entries.
