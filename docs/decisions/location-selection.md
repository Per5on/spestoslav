# Location selection — preview 003

One shared searchable name-only locality selector across Food, Technology, Fuel and My list. Suggestions include municipality and region to distinguish settlements. Preserve the existing canonical locality IDs and imported name catalog.

The owner removed postal search/storage, mode buttons and the interior “Местоположение” label on 15 November 2026. GPS, OSM, current-position and radius flows remain excluded. Historical postal/coordinate data references do not authorize restoring these features.
